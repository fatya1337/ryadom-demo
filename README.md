# Рядом — кабинет психотерапевта

Интерактивное демо для команды: пациенты, история между встречами, график самооценок, заметки и подготовка к сессии.

**Сайт:** https://fatya1337.github.io/ryadom-demo/

Все профили, записи и встречи вымышлены. Приложение не ставит диагноз, не определяет фазу БАР и не даёт рекомендаций по лечению. Не вводите реальные сведения о здоровье.

## Что можно показать

- Поиск пациентов по имени и коду, фильтры доступа.
- Историю пациента и периоды 7/14/30 дней (в демо 14 дней данных).
- Локальные заметки психотерапевта и чек-лист подготовки к встрече.
- Сводку с JSON-выгрузкой и печатью/сохранением PDF средствами браузера.
- Демоприглашение `DEMO-048` и пустую историю нового пациента.
- Закрытый доступ: профиль с отозванным разрешением не открывается.

Дневник пациента и Telegram-бот развивает другая часть команды. Эта публикация содержит только кабинет психотерапевта. Реальная авторизация, API, PostgreSQL и Telegram-синхронизация ещё не подключены. Заметки и чек-лист сохраняются только в браузере. Расписание статическое.

## Локальный запуск

Требуется Node.js 22+.

```sh
npm ci
npm run dev -- --port 3000
```

Открыть http://localhost:3000 . Проверка: `npm run build` и `npm run typecheck`.

## Файлы

- `app/page.tsx` — кабинет и демосценарии.
- `app/globals.css` — дизайн, адаптивность, печатные стили.
- `app/layout.tsx` — оболочка и метаданные.
- `public/favicon.svg` — знак приложения.
- `.github/workflows/pages.yml` — сборка и публикация Pages при изменении main.

## Публикация

В Settings → Pages выбран GitHub Actions. Workflow собирает статический Next.js export с `NEXT_PUBLIC_BASE_PATH=/ryadom-demo` и размещает `out/` на GitHub Pages. Секреты для сборки не нужны.

Production-сервис с общей базой планируется отдельно. Pages используется только для демонстрационного фронтенда.
