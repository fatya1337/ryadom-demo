# Рядом — кабинет психотерапевта

https://fatya1337.github.io/ryadom-demo/

Главная и /showcase/ открывают прежний сайт с реестром пациентов, графиками,
заметками и подготовкой к встречам. Презентационная главная убрана 14.10.2026
по уточнению пользователя: отчёт о разработке нужен в чате, сайт — для работы.

/live/ — расширенный кабинет специалиста с выбором дат, историей, заметками
и подготовкой, /patient/ — дневник, история, план дня и управление доступом.
Все публичные экраны автономные: вымышленные данные в памяти страницы,
изменения сбрасываются при перезагрузке. Кабинеты независимы.
Учебные коды не дают реальный доступ. API, база и авторизация здесь не подключены.
Не вводите настоящие медицинские данные. Browser storage для записей не используется.

Полная серверная версия: barmood-team/platform-doctor (feat/shared-backend)
и platform-biplyar (feat/patient-live). Общие PostgreSQL / Prisma / Better Auth.
Серверные проекты этой правкой не менялись.

## Запуск
npm ci
npm run dev

## Статическая сборка
STATIC_EXPORT=1 NEXT_PUBLIC_BASE_PATH=/ryadom-demo npm run build

GitHub Actions публикует out/ после push в main. Backend, аккаунты и .env сюда
не копировать. В /live/ используется app/live/demo.ts, в /patient/ —
app/patient/demo-client.ts. Не подменять эти модели реальным API незаметно.
