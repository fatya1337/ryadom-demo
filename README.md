# Рядом — единый кабинет психотерапевта

https://fatya1337.github.io/ryadom-demo/

Новые функции встроены в первоначальный дизайн. Главная /, прежняя ссылка
/showcase/ и /live/ открывают один компонент app/live/workspace.tsx. Отдельных
старой и расширенной версий больше нет. /patient/ — личный кабинет пациента.

Реестр с поиском/фильтрами, история и свои даты, настроение/сон/энергия,
поиск в записях, личная заметка, подготовка к встрече, сводка и JSON.
Учебный код DEMO-048 добавляет пустой дневник. «Учебные данные» внизу:
отзыв доступа и сброс. Это симуляции; настоящего приглашения код не создаёт.

Данные вымышлены и хранятся в памяти до перезагрузки. Кабинеты здесь независимы,
API/база/авторизация не подключены. Реальные медицинские данные вводить нельзя.
Личные заметки и подготовка не входят в экспорт дневника.
Серверная версия — barmood-team/platform-doctor (feat/shared-backend), пациент —
platform-biplyar (feat/patient-live), общий PostgreSQL / Prisma / Better Auth.

## Запуск
npm ci
npm run dev

## Сборка Pages
STATIC_EXPORT=1 NEXT_PUBLIC_BASE_PATH=/ryadom-demo npm run build

Actions публикует out/ при push main. Не публиковать .env, аккаунты, backend,
node_modules и сборки. Отчёт о разработке передаётся отдельно, не вместо сайта.
