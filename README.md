# Рядом — кабинет психотерапевта

[Открыть кабинет](https://fatya1337.github.io/ryadom-demo/)

Этот сайт показывает только кабинет психотерапевта. Пациентская часть передаётся другой команде как отдельный проект; общего выбора ролей сейчас нет.

Основной интерфейс: app/page.tsx. Истории вымышленных пациентов, динамика, заметки, подготовка и сводка. Данные только локальные, настоящих API и авторизации нет.

Пациентские модули от предыдущего промежуточного коммита не подключены к главной. Для работы команды используется отдельный пакет ryadom-patient, без кабинета специалиста.

[План дальнейшего объединения](TEAM-HANDOFF.md).

Node.js 22+: npm ci, npm run dev. Проверка: npm run build. GitHub Actions публикует main на Pages. Production с общей БД планируется на Яндекс Клауд.
