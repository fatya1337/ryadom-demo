# Рядом — два пространства

[Открыть сайт](https://fatya1337.github.io/ryadom-demo/) · [Пациент](https://fatya1337.github.io/ryadom-demo/#patient) · [Психотерапевт](https://fatya1337.github.io/ryadom-demo/#therapist)

Общий дизайн и демонстрационный выбор роли, независимые модули двух команд.

Пациент: дневник, история, самооценки, динамика, ритм дня, локальные согласия и удаление данных. Психотерапевт: пациенты, истории, заметки, подготовка и сводка.

**[Передача команде: файлы, границы модулей и контракт API](TEAM-HANDOFF.md).**

Выбор роли — не авторизация. Дневник пациента пока не синхронизирован с реестром специалиста и ботом. Все данные демо локальные, используйте только вымышленные сведения.

## Запуск
Node.js 22+: `npm ci`, `npm run dev -- --port 3000`. Проверка: `npm run build`.

## Файлы
- app/page.tsx — общий вход.
- app/patient-workspace.tsx — интерфейс пациента.
- app/patient-store.ts — типы и локальный адаптер пациента.
- app/therapist-workspace.tsx — кабинет специалиста.
- app/globals.css и app/workspaces.css — дизайн.

GitHub Actions публикует main на Pages. Для production с сервером и общей БД планируется Яндекс Клауд.
